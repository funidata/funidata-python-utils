# Replacement data

Files contained here contain some replacement data for the test data.
Purprose is to use this data here to anonymize/scramble sensitive portions of the test data, such as names, birth dates etc.

## Name lists

All files contain names sorted alphabetically.

These name lists for Finnish names were taken from

[https://www.avoindata.fi/data/fi/dataset/none/resource/08c89936-a230-42e9-a9fc-288632e234f5](https://www.avoindata.fi/data/fi/dataset/none/resource/08c89936-a230-42e9-a9fc-288632e234f5])
